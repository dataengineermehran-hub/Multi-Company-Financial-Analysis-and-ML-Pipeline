Multi-Company Financial Analysis & Machine Learning Pipeline (Airflow + SQLite + Scikit-Learn)An end-to-end data and machine learning pipeline built with Apache Airflow, SQLite, and Scikit-Learn that ingests multi-company financial statements from raw Excel files (.xlsx), standardizes Persian/Arabic text and numbers, engineers financial features and ratios, trains classification and regression models, and audits output tables.Project Path: C:\Users\mehran\PycharmProjects\pythonProject\financial_statement1. Plain-Language Overview: What Does This System Do?Financial statements across multiple companies and sheets (such as Income Statement, Balance Sheet, and Cash Flow) often come with formatting inconsistencies, including:Persian or Arabic digits (۰۱۲۳... or ٠١٢٣...), comma separators, or negative numbers enclosed in parentheses (123)Half-spaces (ZWNJ) and character variations (ي/ی and ك/ک)Inconsistent file names or Persian sheet namesThis pipeline automates the entire workflow in 4 sequential Airflow tasks:Ingest Excel Sheets to Tables (ingest_excel_to_tables): Reads .xlsx files from data\raw, extracts company names and financial periods (YYYY/MM/DD), maps sheet names to standardized English table names (tbl_*), and stores structured records in SQLite.Validate & Engineer Features (validate_and_build_features): Records numeric/null row counts (ml_validation_summary) and computes financial features and ratios from income statement, balance sheet, and cash flow data—such as gross margin, operating margin, net margin, ROA, ROE, year-over-year revenue growth (YoY), and profitability labels (is_profitable)—stored in ml_financial_features.Train Models & Save Predictions (train_and_predict_models): Trains two core scikit-learn models:Classification (LogisticRegression): Predicts company profitability (is_profitable) and probability scores.Regression (Ridge): Predicts net profit margin (net_margin) and compares MAE and RMSE against a mean baseline (DummyRegressor).Audit Output Tables (audit_output_tables): Verifies that all expected tables exist in the SQLite database and contain non-zero row counts.2. Key Use CasesUnified Multi-Company Financial Analysis: Consolidates scattered Excel financial statements into a single queryable SQLite database (companies_financial_1403.db).Financial Data Standardization: Cleans inconsistent Persian/Arabic characters, number formats, and sheet names for downstream analytics and reporting.Quantitative Profitability & Margin Diagnostics: Computes financial ratios automatically and tracks feature weights (ml_feature_weights) across classification and regression models.Foundation for BI, APIs, or Enterprise Databases: Produces structured tables in SQLite that can feed dashboards, reporting tools, or relational server databases.3.
